# Marketing Genius

Build a simple, fun marketing studio that helps the owner make good marketing for four separate businesses.

## The four businesses
- **Retroscore Collectibles and Gifts:** retro collectibles, gifts and 80s/90s nostalgia.
- **GO!VCR:** VCRs, VHS equipment, parts and repair.
- **GO!VCR PropSup:** retro props and hire.
- **Terilliom Developments:** practical technology, AI and automation solutions.

Keep each business's details and voice separate. Never invent stock, prices, guarantees, results or capabilities.

## Keep the app simple
Home · Create · To review · Plan · Saved work · Businesses & tools.

The owner should be able to start a campaign quickly, edit the copy, save it, review it and export it. Save work on the device. Clearly say when a live AI or social connection is not configured. Never claim a post was published unless the platform confirms it.

## Creative rules
- Positive, playful, energetic and human. Make it fun.
- Use tasteful animations and optional sound effects. Sound starts OFF, with an obvious toggle. Never play audio unexpectedly.
- Keep screens clean and uncluttered. No walls of data, jargon, busy dashboards or unnecessary steps.
- One clear message, readable text, useful images and an obvious next action.
- Proofread. If a fact is unknown, ask for confirmation or leave it out.
- Owner approves before anything is published or money is spent.

## Build and release
Use the existing GitHub project and preserve working features. Prefer free/open-source tools. Make the phone experience the priority. Run available checks, fix errors and report only verified results. A preview is not the same as a tested release.
